# AI Swing Trader

## 概要

米国株を対象とした、個人向けAI支援型スイングトレードシステム。

本システムは、株価データ・テクニカル指標・ニュース・市場環境などを分析し、
設定したルールに基づいて投資候補を抽出することを目的とする。

最終的な投資判断は人間が行い、AIは分析・情報整理・候補抽出を支援する。

---

## 基本方針

- 対象市場：米国株
- 投資スタイル：スイングトレード
- 監視銘柄：約25〜30銘柄
- 主な対象：大型株・高流動性の成長株
- AIの役割：情報収集・分析・スコアリング・候補抽出
- 最終判断：人間が実施

---

## システム構成（予定）

### Phase 1
監視銘柄リストの管理

### Phase 2
株価データ・ニュース情報の取得

### Phase 3
監視項目によるスコアリング

### Phase 4
エントリー候補の抽出

### Phase 5
AIによるニュース・材料評価

### Phase 6
売買ルールの管理

---

## 現在の基本ルール v1.0

### 監視対象

米国大型株・高流動性の成長株を中心に監視する。

初期監視銘柄数：約27銘柄。

---

### 買い候補ライン

総合スコア75点以上を買い候補として抽出する。

---

### リスク管理

1銘柄あたりの投資額を限定し、
複数銘柄へ分散する。

損失管理を最優先とし、
1回のトレードで大きな損失を発生させない。

---

## 開発方針

プログラミング未経験者でも理解できるよう、
小さな機能から段階的に開発する。

まずは、

1. データを見る
2. 情報を整理する
3. スコアリングする
4. 買い候補を表示する

という順番でシステムを構築する。

---

## 注意事項

本システムは投資助言を目的とするものではない。

AIによる分析結果は投資判断の補助情報として使用し、
最終的な売買判断および投資責任は利用者自身が負う。
